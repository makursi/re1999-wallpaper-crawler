# 重返未来：1999 壁纸下载器

**中文** | [English](README.en.md)

工具从[官网](https://re.bluepoch.com/home/detail.html#wallpaper)下载全部壁纸到本地，并在一个页面里浏览。服务只在个人本地运行，其他设备无法访问。

![壁纸墙](docs/screenshots/console-zh.webp)

## 准备

安装 Node 22 和 pnpm。在项目根目录中打开终端（Windows 用 PowerShell），执行：

```bash
pnpm install
pnpm build
```

`pnpm build` 产出程序本身（`build/`）：两个打包好的入口和预构建的页面。程序只从这份产物运行，启动时不再编译任何东西——所以拉下代码后要先构建一次。

## 启动

```bash
pnpm webui
```

浏览器打开：

```
WebUI: http://127.0.0.1:8791/?token=……
```

## 页面

镜像 1013 是本地已有的张数，官方清单 1010 是官网现有的张数。下一行给两个数：官网有、本地没有的张数，以及本地有、官网清单里已经没有的个数。

## 运行期间

一次运行先向官网要一份完整清单，再并行下载清单里的每一张：没有浏览器窗口，也不需要登录。

按 Ctrl+C 结束服务，未完成的下载也会停止。

已经存在的文件会跳过，只下载新增的壁纸。

## 结果

运行结束后，“运行”面板给出三种结论之一：

- 干净：没有发现问题。
- 已解释：出现的是常规情况，例如本地多了几张官网已删除的图。这些情况记录在案，不影响使用。
- 缺陷：这次没有读到官网清单，或有文件下载失败。再运行一次通常可以解决。

## 常见问题

- 提示“先完成站点配置”：缺少 `.env` 文件。在项目根目录新建文件，命名为 `.env`，写入一行。

  ```
  BASE_ORIGIN=https://re.bluepoch.com
  ```

## 文件位置

- `images`：壁纸文件。
- `logs`：每次运行写一个 JSONL 日志。
