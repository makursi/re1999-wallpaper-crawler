# 重返未来：1999 壁纸下载器

**中文** | [English](README.en.md)

工具从[官网](https://re.bluepoch.com/home/detail.html#wallpaper)下载全部壁纸到本地，并在一个页面里浏览。服务只在你自己的电脑上运行，其他设备访问不到。

![壁纸墙](docs/screenshots/console-zh.webp)

## 准备

装好 Node 22、pnpm 和 Chrome。在本文件夹打开终端（Windows 用 PowerShell），逐行执行：

```bash
npm install -g @playwright/cli
npx playwright-cli install
pnpm install
```

## 启动

```bash
pnpm webui
```

终端打印一行地址，浏览器自动打开它：

```
WebUI: http://127.0.0.1:8791/?token=……
```

第一次启动会先构建页面，之后直接复用，启动更快。浏览器没有自动打开时，把这行地址完整复制到地址栏；token 是访问凭据，去掉就打不开。

## 页面

壁纸按五列铺开，每张按原图比例显示，不裁剪。灰色轮廓的格子表示官网有、本地还没有。

点一张打开原图，可放大缩小，按 Esc 关闭。

右上角“运行”开始下载。运行期间会打开一个 Chrome 窗口，自动翻页并保存新壁纸。

镜像 1013 是本地已有的张数，官方清单 1010 是官网现有的张数。下一行给两个数：官网有、本地没有的张数，以及本地有、官网清单里已经没有的个数。

页面可随时切换中文和 English，选择会被记住。

## 运行期间

Chrome 窗口会自己翻页，不要点击其中的元素，也不要关闭它。

关闭网页不会停止下载。按 Ctrl+C 结束服务，未完成的下载也会停止。

已经存在的文件会跳过，只下载新增的壁纸，因此可以重复运行。

## 结果

运行结束后，“运行”面板给出三种结论之一：

- 干净：没有发现问题。
- 已解释：出现的是常规情况，例如官网背景图被正确排除、本地多了几张官网已删除的图。这些情况记录在案，不影响使用。
- 缺陷：这次没有抓全，或有文件下载失败。再运行一次通常可以解决。

## 常见问题

- 提示“先完成站点配置”：缺少 `.env` 文件。在本文件夹新建文本文件，命名为 `.env`，写入两行，保存后刷新页面。

  ```
  BASE_ORIGIN=https://re.bluepoch.com
  PAGE_PATH=/home/detail.html
  ```

  Windows 资源管理器不允许文件名以点开头，可以在末尾多打一个点（`.env.`），系统会去掉这个点。

- 提示“孤儿运行”：上次运行中断，日志停在报告之前。在页面上点“清理”，关闭残留的浏览器会话，然后重新运行。日志本身不会被修改或删除。

- 格子标注“未落盘”：官网有这张，本地还没下载，下次运行会补上。

- 需要排查：保留 `logs` 文件夹里最新的日志文件，它记录了这次运行的全过程。

## 文件位置

- `images`：壁纸文件。
- `logs`：每次运行写一个 JSONL 日志。
