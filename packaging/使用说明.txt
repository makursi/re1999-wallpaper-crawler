重返未来：1999 壁纸下载器 · 使用说明
====================================

一、这是什么
------------
这个工具把《重返未来：1999》官网壁纸页上的壁纸全部下载到你的电脑里，
再用一个本地页面展示出来。它只在你自己的电脑上运行，其他设备访问不到；
除了启动时向 GitHub 查一次有没有新版本，它不向外发送任何东西。

壁纸的版权归官方（Bluepoch）所有。这个工具本身不存储、也不分发壁纸：
它只是把官网公开提供的图片保存到你自己的电脑上。


二、解压到哪里
--------------
把压缩包解压到任意文件夹都可以，路径里有中文、有空格也没问题。
建议放在一个固定的位置（例如 D:\游戏\重返未来壁纸），以后更新时好找。

注意：必须先解压，不能直接在压缩包里双击运行。

解压后你会看到：
  启动.bat       双击它，启动程序
  更新.bat       有新版本时，用它替换程序
  使用说明.txt   就是本文件
  app\           程序本身。不要修改，也不要删除
  data\          你的东西：壁纸、日志、设置。第一次启动后才会出现

新版本的压缩包不要解压到旧文件夹里覆盖。更新请按第五节的步骤做。


三、启动和停止
--------------
双击 启动.bat。

会弹出一个黑色窗口，标题写着“关闭这个窗口或在页面上退出就是停止”。请让这个窗口一直开着。
浏览器一般会自动打开壁纸页面；如果没有，把窗口里显示的那行网址复制到浏览器打开。

要停止程序，有两种方法：
  · 关闭这个黑色窗口；
  · 在页面顶部导航条里点“退出”。
如果正好在抓取或下载，页面会先问一次；确认后，这次运行会中断，下次启动时需要先在“运行”面板里清理中断的记录。
程序退出后，黑色窗口不会立刻消失：按任意键（例如空格或回车）才会关闭，这样你可以读到窗口里最后几行中文。

关掉浏览器的标签页不会停止程序，也不会停止下载。

再次双击 启动.bat 不会启动第二个程序：它只会把浏览器指回正在运行的那个页面。
窗口被关掉之后再双击，才会重新启动。


四、第一次抓取
--------------
第一次打开时墙上是空的。点页面顶部导航条里的“运行”，在打开的面板里点“开始运行”。

点它之后，程序会先向官网要一份完整清单，然后开始下载：
  · 大约 1000+ 张壁纸
  · 总共约 2 GB
  · 视网速不同，大约需要 10–40 分钟

下载期间请不要关闭那个黑色窗口，也不要让电脑休眠或断网。
窗口里会显示“抓取已开始：下载期间请不要关闭这个窗口”。

如果中途断网、没电，或者你主动停止了程序，都没关系：
下次双击 启动.bat，再点“开始运行”，已经下载好的会跳过，只补没下完的。

抓完之后，页面上的数字会告诉你结果：官网有多少张、本地有多少张。
两个数字对得上，就说明这次抓全了。如果差得比较多，再点一次“开始运行”即可。


五、更新到新版本
----------------
1. 打开项目的 Releases 页面：
   https://github.com/makursi/re1999-wallpaper-crawler/releases
   下载最新版本的 zip。
2. 把新 zip 解压到一个新的文件夹（不要解压进旧文件夹）。
3. 先停止正在运行的程序（关闭黑色窗口，或者在页面上点“退出”）。
4. 双击新文件夹里的 更新.bat。

程序会记住上次安装的位置，把旧的 app\ 换成新的，旧的留作 app.old\。
你的 data\（壁纸、日志、设置）不会被改动。

如果窗口提示“没有找到上次安装的位置”，说明安装文件夹被改名或搬走了：
把旧文件夹里的 启动.bat 拖到新文件夹的 更新.bat 上松手，再按提示操作。
拖整个旧文件夹、或者它的 app 文件夹，也可以。

更新完成后，以后都双击安装文件夹（原来那个文件夹）里的 启动.bat。
新解压出来的那个文件夹已经没有用了，可以删掉。


六、更新后打不开？回退到上一版
------------------------------
新版本如果启动不了，可以退回上一版：

1. 关闭所有程序窗口。
2. 打开安装文件夹，把现在的 app 文件夹改名为 app.broken（或者直接删掉）。
3. 把 app.old 改名为 app。
4. 双击 启动.bat。

app.old 只保留最近一次更新前的版本。再更新一次，它会被更早的旧版本覆盖。
如果 app.old 已经不存在，说明还没有更新过，或者已经回退过一次。


七、卸载
--------
关闭程序，然后删除整个安装文件夹即可。
程序不写注册表、不开机启动、不安装后台服务。

如果想连“上次安装位置”的记录也清掉，可以再删除这个文件夹：
  %LOCALAPPDATA%\re1999-wallpaper-crawler
（在文件资源管理器的地址栏输入这一行，回车即可。）


八、你的东西在哪里
------------------
都在 data 文件夹里：

  data\images\     下载好的壁纸
  data\logs\       每次运行的日志（排查问题时有用）
  data\cache\      缩略图缓存，可以随时删除，程序会重新生成
  data\user.env    可选。你自己的设置，更新不会覆盖

更新只会替换 app\，不会动 data\。备份时复制整个 data\ 即可；
换电脑时把 data\ 一起带过去，壁纸和日志都还在。


九、被 Windows 或杀毒软件拦下
------------------------------
这个程序没有数字签名，从网上下载的压缩包也可能被 Windows 标记为
“来自其他计算机”（Mark-of-the-Web）。表现是：页面空白、缩略图不显示，
或者双击后程序根本起不来。

先试这个（推荐）：
  右键点击下载的 zip 文件 → 属性 → 在“安全”一栏勾选“解除锁定” → 确定，
  然后重新解压。

已经解压了也可以：
  右键点击解压后的文件夹 → 属性 → 勾选“解除锁定” → 确定。
  或者在该文件夹里打开 PowerShell，运行：
     Get-ChildItem . -Recurse | Unblock-File

如果 Windows SmartScreen 弹出“Windows 已保护你的电脑”，点“更多信息”，
再点“仍要运行”。

如果杀毒软件报毒或直接删除文件：这是没有签名的独立程序常见的误报。
请把整个文件夹加入信任或排除列表，再重新解压一次。
程序只访问官网和它的图片服务器，以及 GitHub 的版本查询，不会上传你的文件。


十、需要装 Chrome 吗？
----------------------
不需要。这个工具不再使用浏览器自动化，也不要求安装 Chrome、Node.js
或任何命令行工具。它自带运行环境，只借用你电脑上的浏览器来显示页面。


十一、出错了找谁
----------------
先看页面“运行”面板里的结论，以及 data\logs\ 里最新的一份日志。

仍然解决不了，请到项目的 Issues 页面提问：
  https://github.com/makursi/re1999-wallpaper-crawler/issues

提问时请附上：
  · 页面顶部导航条上显示的版本号
  · data\logs\ 里最新日志的文件名
  · 你看到的那句话或截图

请不要在公开的 Issue 里贴出你的完整路径、用户名等个人信息。
