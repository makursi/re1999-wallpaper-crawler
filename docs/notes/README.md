# Design notes: one file per topic

Every file here is one topic's decision tree — the question, the settled
branches, the open branches, and the rejected branches with their reasons. The
convention is `docs/agents/design-notes.md`; read it before writing here.

The reader is the next agent opening the same question. Name the file for the
topic in kebab-case, not for a date or an issue number, so a question that comes
back updates one note instead of forking a second.
